# Model files

Model weights are intentionally kept outside this source repository. Obtain
each model from its upstream publisher and follow that model's current license,
attribution and redistribution terms.

The synthesis code expects model artifacts below `models/artifacts/`. The
application code and the verification guide identify the required language
and precision paths. Do not treat the MIT license for this repository's source
code as a license for model weights.

Upstream model families:

- [EchoBharat models](https://huggingface.co/RaunakSaha/echobharat-models) —
  FastPitch plus HiFi-GAN for nine languages.
- [Facebook MMS Odia TTS](https://huggingface.co/facebook/mms-tts-ory) — VITS
  model for Odia.
