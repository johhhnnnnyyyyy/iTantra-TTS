# iTantra TTS

Browser interface for the local multilingual TTS research pipeline. It
supports the ten-language matrix, speech normalization, immediate audio
playback, model selection and request-scoped performance metrics.

The application source is provided here for reproducible packaging. Model
weights are separate upstream artifacts and are not included in this source
release. Each model retains its own license and attribution requirements; the
project MIT license applies to the source code only.
